Notes on an infinite canvas

Markdown notes with their images and videos, side by side on a canvas that never ends. Link them into mindmaps, tick off tasks, find anything in any project. Free, open source, no account.

Features

Somewhere to put everything while you think: text, pictures, code and the lines between them.

Infinite canvas

Zoom, pan and arrange notes freely, with a minimap, smart guides and sections that group what lies in them.

Images and videos in notes

Paste or drop screenshots, photos and videos straight into a note. Videos play inside it.

Copy into Teams

A note goes onto the clipboard as rich text with its images, ready for Teams, Outlook or Word.

Links and mindmaps

Connect any side to any side. Tab grows a mindmap, [[links]] join notes across projects, with previews.

Search every project

Full-text search over all notes at once, forgiving of typos and half-typed words.

Checklists

Tick tasks right in the note; the sidebar collects the open ones of every project.

Code snippets

Fenced code is highlighted in the theme's colours, the language guessed if you leave it out.

Whiteboard tools

Shapes, free text, pen and highlighter, and templates from Kanban board to retrospective.

Plain files, with history

Every note is a Markdown file in a folder you choose. Earlier versions are kept, and restored with a click.

Notes that hold what you paste

Rich text from Teams, Outlook, Word or a web page keeps its headings, lists, links and tables. Images are saved with the note, spreadsheet cells become a table, a web link gets the page's title, and any other file becomes a card that opens it.

Find it again, even misspelled

The search box at the top of the sidebar looks through every note of every project. relese still finds “release”; results come grouped by project with the matches in bold, and are highlighted inside the notes.

Installation

Step by step for your system. Your notes live in their own folder and stay where they are through updates and uninstalling.

Windows 10 and 11

Install

  1. Download the installer (cache-windows-x64-setup.exe) above and double-click it.
  2. Windows says “Windows protected your PC”, because the program isn't digitally signed yet. Click More info, then Run anyway.
  3. Choose who to install for: only you (recommended, no administrator rights) or every user of the computer (asks for an administrator).
  4. The boxes Start menu entry and Create a desktop shortcut are ticked; untick what you don't want, then Install.
  5. Cache starts at the end. Later you find it in the Start menu and on the desktop.

The program always goes to the same place: %LOCALAPPDATA%\Programs\Cache (for all users: C:\Program Files\Cache). Your notes are in Documents\Cache.

Update

Run the installer of the new version; it replaces the old one and keeps your choices of shortcuts.

Remove

Windows Settings › Apps › Installed apps › Cache › Uninstall. Your notes stay in Documents\Cache.

Without installing: unzip the zip archive and start cache.exe. There is no Start menu entry then.

macOS (Apple silicon and Intel)

Cache isn't notarised by Apple yet (that costs a yearly fee), so macOS blocks its first start. Once allowed, it starts normally from then on.

Install

  1. Download cache-macos.dmg above and double-click it.
  2. Drag Cache from the window into the Applications folder, then eject the “Cache” drive in the Finder's sidebar.
  3. Double-click Cache in Applications. macOS says it can't be opened because Apple couldn't check it for malicious software. Click Done, not “Move to Bin”.
  4. Open System Settings › Privacy & Security and scroll down to Security, where it says “Cache” was blocked. Click Open Anyway. The button shows only for a while after the attempt; if it's missing, repeat step 3.
  5. Confirm with your password or Touch ID and choose Open Anyway once more. From now on a double-click is enough.

For the experienced: instead of steps 3 to 5, xattr -dr com.apple.quarantine /Applications/Cache.app in the Terminal lifts the block for this app.

Update and remove

Quit Cache, drag the new version into Applications and choose Replace, then repeat steps 3 to 5. To remove it, drag Cache from Applications to the Bin; your notes stay in ~/Documents/Cache.

Linux

AppImage (any distribution)

  1. Download cache-linux-x64.AppImage and put it somewhere for good, for example ~/Applications.
  2. Make it executable: in the file manager under Properties › Permissions, or in a terminal with chmod +x cache-linux-x64.AppImage.
  3. Double-click it. If it doesn't start and mentions FUSE (on some servers, containers and very slim systems), start it with ./cache-linux-x64.AppImage --appimage-extract-and-run, or take the .deb on Debian and Ubuntu.

Debian and Ubuntu

sudo apt install ./cache-linux-x64.deb installs it with an entry in the application menu; a new version installs the same way. Remove it with sudo apt remove cache.

Either way your notes are in ~/Documents/Cache and stay there when the program goes.

Questions

What does Cache cost?

Nothing. It is open source under the MIT license and free to use and pass on.

Where are my notes kept?

In a folder on your computer, Documents/Cache unless you choose another one (at the bottom of the sidebar). Each project is a folder, each note a Markdown file any editor can open, and pictures and videos sit in the project's assets folder. Nothing is sent anywhere.

Can I sync notes between computers?

Put the workspace folder into a folder your cloud drive syncs (OneDrive, Dropbox, iCloud Drive, Nextcloud) and choose it in Cache on every computer.

How do I get a note into Teams?

Select the note and press Ctrl+C (Cmd+C on a Mac), then paste in Teams. Text, images, tables, code and checklists come along. Ctrl+Shift+C copies the selection as a picture instead.

Windows or macOS warns at the start. Is that dangerous?

The program isn't digitally signed (yet), so Windows SmartScreen warns and macOS blocks the first start. The installation guide shows how to start it anyway. The source code is public.

Something is missing or doesn't work.

Ideas and problems are welcome as an issue on GitHub.
